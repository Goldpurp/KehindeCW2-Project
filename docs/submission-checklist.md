# Submission Checklist

## Before Recording

- Confirm the Render home page loads.
- Confirm both existing demonstration accounts can sign in.
- Retrieve the creator invitation code only if a new creator account is required: open Passwords/Keychain Access and search for `kehindeScalableSolution Creator Signup Code`.
- Keep Azure Portal tabs ready for the Function App, Cosmos DB Data Explorer and the `videos` Blob container.
- Use a small disposable video so upload and deletion complete within the recording.
- Do not show passwords, bearer tokens, connection strings or Azure app-setting values.

## Five-Minute Recording

Follow the timed script in slide 11 speaker notes:

1. `0:00-0:40` - deployed Render site, GitHub source and protected Azure endpoint.
2. `0:40-1:25` - consumer login, role-limited navigation, logout confirmation, creator login.
3. `1:25-2:20` - creator upload with caption, genre and age rating; explain authenticated producer/publisher.
4. `2:20-3:40` - consumer search, autoplay, seeking, like, comment and rating.
5. `3:40-4:35` - Cosmos records, private Blob object and notification update.
6. `4:35-5:00` - owner deletion, feed refresh and backend removal.

## Embed the Video

1. Open `kehindeScalableSolution Presentation - Final.pptx`.
2. Select slide 11, then select the large demonstration image frame.
3. Insert the MP4 using PowerPoint's **Insert > Video > This Device** command.
4. Resize the video to the inherited frame without covering the timeline on the right.
5. Set playback to start automatically or when clicked.
6. Save, close and reopen the deck, then play the slide once to confirm the video is embedded and audio is present.

## Final Submission Gate

- PowerPoint opens without repair warnings.
- Exactly 14 slides are present.
- Slide 11 contains an embedded video shorter than five minutes.
- Student name and number are correct on the title slide.
- References and access date are present.
- The live application and API respond.
- No credentials, `.env` files, local settings or secrets are included.
- Upload the final `.pptx` to the assessment area, not a PDF export.
